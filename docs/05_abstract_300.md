# 05 摘要（約 300 字）

> 由 `docs/01_abstract_A2F.md` 濃縮；數字出處見 `docs/references.md`。

建築占 2025 年全球用電增量近 45% [D1]，臺灣服務業與住宅部門合計約占全國用電 36.6% [D15]，但從電表異常到可執行調查仍仰賴人工；單一門檻難以區分天氣、營運與資料問題，LLM 直接判讀數值亦不可靠 [A6]。本專題提出 Energy Detective AI Agent：以 Building Data Genome 2 歷史電表重播，由 Python 執行品質檢查、同星期×小時基準與校準門檻偵測事件，LLM 僅在工具白名單內規劃並選擇條件式領域規則，報告每個數值須綁定證據並通過驗證，否則降級為固定模板。評估預定比較兩種基準、合成擾動命中率，及固定報表、固定流程加 LLM 與 Agent 三組在十個案例的任務成功率與事實可追溯率。預期產出可重現且不過度推論的調查原型；尚未實驗，不宣稱故障確診或節電成效。
